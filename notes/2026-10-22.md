## Odd and Even Measurements (GROUP BY version)
```sql
-- Input grain: one row = one measurement; several per day
-- Output grain: one row = one measurement_day (measurement_day, odd_sum, even_sum)
-- Window needed? yes, because odd/even is each measurement's POSITION within
--   its day -> ROW_NUMBER partitioned by day; the sums are plain GROUP BY
-- Keep a row when: every day is kept, one row per day; no filtering
WITH numbered AS (
  SELECT
    CAST(measurement_time AS DATE) AS measurement_day,
    measurement_value,
    ROW_NUMBER() OVER (
      PARTITION BY CAST(measurement_time AS DATE)
      ORDER BY measurement_time   -- no tie-breaker: measurement_time is unique
    ) AS measurement_num
  FROM measurements
)
SELECT
  measurement_day,
  SUM(CASE WHEN measurement_num % 2 = 1 THEN measurement_value ELSE 0 END) AS odd_sum,
  SUM(CASE WHEN measurement_num % 2 = 0 THEN measurement_value ELSE 0 END) AS even_sum
FROM numbered
GROUP BY measurement_day
ORDER BY measurement_day;
```
- My accepted version used SUM() OVER + DISTINCT. It worked because a window with
  no ORDER BY puts the same day total on every row -> rows identical -> DISTINCT
  collapses them. (P4 Oct 21: MAX OVER ORDER BY = running values -> DISTINCT failed.)
- Mixing GROUP BY and SUM() OVER on the same SUM -> error (rnk not grouped).
  SUM() OVER keeps every row; SUM() + GROUP BY = one row per group. Never both.
- Dialects: MySQL DATE(ts), %; BQ DATE(ts), MOD(n, 2); Postgres ts::date, %.

## #585 Investments in 2016 (hinted)

-- Input grain: one row = one policy (pid, tiv_2015, tiv_2016, lat, lon)
-- Output grain: one row = one number (the total tiv_2016)
-- Window needed? yes, because each row needs two group sizes (rows sharing its
--   lat/lon, rows sharing its tiv_2015) and must stay a row so I can filter it
-- Keep a row when: its (lat, lon) count = 1 AND its tiv_2015 count > 1
WITH with_counts AS (
  SELECT
    tiv_2016,
    COUNT(*) OVER (PARTITION BY tiv_2015) AS same_tiv_2015,
    COUNT(*) OVER (PARTITION BY lat, lon) AS pair_count
  FROM Insurance

SELECT ROUND(SUM(tiv_2016), 2) AS tiv_2016
FROM with_counts
WHERE same_tiv_2015 > 1 AND pair_count = 1;
