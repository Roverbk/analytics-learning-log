## P3: Cards with 3+ consecutive txn days — SOLVED (with hints)

```sql
-- Output grain: one row = one card with a 3+ day streak
-- Input grain: one row = one transaction
-- Window needed? yes, because days must be numbered in date order within each card
WITH days AS (
  SELECT DISTINCT card_id, txn_date FROM transactions
),
numbered AS (
  SELECT card_id, txn_date,
         ROW_NUMBER() OVER (PARTITION BY card_id ORDER BY txn_date) AS rn
  FROM days
),
islands AS (
  SELECT card_id, txn_date, DATE_SUB(txn_date, INTERVAL rn DAY) AS island
  FROM numbered
)
SELECT DISTINCT card_id
FROM islands
GROUP BY card_id, island
HAVING COUNT(*) >= 3;
```
Result: C1

### Why it works (interview answer)
Within a streak, date and row number both rise by 1, so date - rn stays
constant. That constant labels the streak, so I group by it and count.
I dedupe to one row per card per day first, because a same-day duplicate
raises rn without raising the date, which shifts the labels and can join
days that aren't actually consecutive.

### Bugs I hit (and fixed)
1. ROW_NUMBER ordered by merchant_id instead of txn_date -> streak scrambled
2. No dedupe -> C2 became a FALSE POSITIVE (Feb 7, 8, 8, 10 looked like a streak)
3. DISTINCT on card_id, merchant_id, txn_date, amount didn't remove the
   duplicate day. DISTINCT dedupes at the grain of the selected columns.
4. ORDER BY inside a CTE does nothing; only ORDER BY inside OVER() matters
